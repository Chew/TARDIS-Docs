# Sonic Resonance

![Sonic circuit](https://github.com/eccentricdevotion/TARDIS-Resource-Pack/blob/master/assets/tardis/textures/item/circuit/circuit_sonic.png?raw=true)

The [Charm](/sonic-screwdriver#charm) upgraded Sonic Screwdriver allows players to tempt mobs by changing the pitch of the sonic screwdriver - this is done by holding a mineral in your offhand while using the sonic device. Each material makes the sonic sound resonate at a different pitch causing any associated mob within range to come towards the player.

### Pitch values

Pitch values are calculated from each material's baseline speed of sound (1,850 m/s for Resin up to 12,000 m/s for Diamond). These are then scaled linearly from 0.50 to 2.00, which maps cleanly onto standard Minecraft sound-engine pitch multipliers (where 1.0 represents normal/baseline pitch).
