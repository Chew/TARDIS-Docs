# Perception Filter

You can craft a Perception Filter to make yourself partially invisible.

![Perception Filter](https://github.com/eccentricdevotion/TARDIS-Resource-Pack/blob/master/assets/tardis/textures/item/key/perception_filter.png?raw=true)

![Perception filter invisibility](/images/docs/perception_filter.jpg)

Type the command `/tardisrecipe filter` in game to view the crafting recipe.

Once crafted you can equip the Perception Filter in your chest armour slot by right-clicking air with the filter in
hand.

To disable the filter just remove it from the chest armour slot.

:::info

When travelling between worlds, the Perception Filter may go completely invisible — if this happens, just
press your “sneak” key (usually LEFT-SHIFT) to make the player skin update.

:::

## Permission

To allow players to use the Perception Filter they will need the permission `tardis.filter`.

## Configuration

To enable or disable the Perception Filter on the server set the configuration option in _config.yml_:

```
allow:
   perception_filter: [true|false]
```

Or use the command `/tardisconfig perception_filter [true|false]`

A server restart is required.
