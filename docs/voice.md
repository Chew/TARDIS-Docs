# Handles voice chat

The TARDIS plugin integrates with the SimpleVoiceChat [mod](https://modrinth.com/plugin/simple-voice-chat) and server [plugin](https://modrinth.com/plugin/simple-voice-chat/versions?l=paper) so that [Handles](handles) can listen to voice commands.

* Install the SimpleVoiceChat mod in your Minecraft client.
* Install the SimpleVoiceChat plugin in your Paper server.
* Start the server - on first run, the TARDIS plugin will detect SimpleVoiceChat and download and initialise the language model for speech-to-text recognition (~40MB download).
* To interact with Handles, instead of typing in chat, you can now just talk.
* You will still need to prefix your commands like you do in chat e.g. say "hey handles" and then your request.
* Just the `core-commands` in _handles.yml_ are supported at this time, not setting reminders.
