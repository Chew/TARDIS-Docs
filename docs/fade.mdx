# Fade Desktops

From TARDIS v7.1.5 the plugin includes the Fade desktop theme. This theme is inspired by the [TARDIS discovery](/discovery) temples.

The desktop uses 12 variants of gradient blocks which are randomly placed so that no two consoles will ever be exactly the same.

The Fade variants have their own page in the [Desktop Theme](/desktop-theme) GUI.

## Configuring a seed blocks

If you have crafted the Fade [seed block](/creating-a-tardis) (using Orange Poplar Leaves) you will need to configure which variant the seed block will grow. To do this:

- Run the command `/tardis fade`
- A dialog (or Bedrock form) will open - hover over the blocks to see a preview of the gradient blocks
- Click the button that corresponds to the gradient you like best
- The seed block will be updated with the gradient data
- Place and activate the seed block as normal
